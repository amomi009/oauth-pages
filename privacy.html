Privacy Policy

Last updated: 2026-10-02

"Daily Report Automation" is a personal/internal automation tool with a single owner and operator. It is not distributed to, or used by, the general public.

What it accesses

The tool requests the Google Drive scope https://www.googleapis.com/auth/drive.file. This scope only allows the application to create and manage files that it itself creates in Google Drive — it cannot view, modify, or delete any other file already in the account's Drive.

What it does with that access

Once authorized by the account owner, the tool periodically uploads a single report file (a .zip containing an HTML summary and a JSON data file) that it generates itself, into one folder the owner has designated. No other data is read from or written to Google Drive.

Data retention and sharing

No data collected or accessed by this tool is shared with, sold to, or processed by any third party. The only systems involved are the tool owner's own Google account and the owner's own automation infrastructure.

Contact

Questions about this tool or policy can be directed to its owner at the support email listed in its Google OAuth consent screen configuration.
